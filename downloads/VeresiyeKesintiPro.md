ZIP dosya sayfasında **Download raw file** ile indirin. Windows paketini tamamen çıkartıp `VeresiyeKesintiPro.exe` dosyasını açın; bağımlılıkları aynı klasörde tutun.

Windows ZIP çapraz derleme çıktısıdır; Windows'ta çalıştırılarak doğrulanmadı. Setup.exe değildir. 23 motor/Excel kontrolü geçti. Kaynak dosyada bulunmayan `KesintiRaporuFinal_KarakterDuyarsiz` makrosunun davranış uyumu ve gerçek personel verileriyle test tamamlanmadı. Ayrıntılar kaynak README içindedir.
