# POS Kasa Yönetim — Build v26

Lacivert/turkuaz POS terminali ve kayıt/fiş sembolü içeren yeni uygulama simgesi eklendi. icon.ico Windows için 16, 24, 32, 48, 64, 128, 256 piksel boyutlarını içerir. icon.png uygulama başlığında gösterilir. Orijinal yüksek çözünürlüklü logo logo-pos-kasa.png dosyasındadır.

Uygulama sürümü 1.0.4. Ad, appId ve kullanıcı kayıt anahtarları değişmedi. Finans hesapları, kayıtlar ve Build v25 güvenlik özellikleri korunur. 35 güvenlik testi ve 17 hesaplama kontrolü/JSX derlemesi geçti. Windows x64 hedef derlemesi başarılı; paket içindeki yeni ikonlar ve çalışma dosyaları kaynakla karşılaştırıldı. Gerçek Windows cihazında çalıştırma testi yapılmadı.

Önce JSON yedeği alın. Node.js 22+ LTS ile pos-app/BUILD.bat kullanılır. Mevcut uygulamanın verilerini silmeyin. Windows eski kısayol simgesini önbellekte tutabilir; yeni derlenen uygulama dosyasını kontrol edin ve gerekiyorsa yalnız kısayolu yeniden oluşturun. Kayıt klasörünü temizlemeyin. Bu ZIP tam kaynak projedir, EXE paketi değildir.
